### Tech stack:

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **TanStack Query**
- **Zustand**
- **React Hook Form**
- **Zod**
- **Next-intl**
- **Shadcn**
- **Playwright**

<br>

### Deployed URL:

- [https://rl-hw-260312.vercel.app](https://rl-hw-260312.vercel.app)

<br>

### Getting started:

**Frontend (/app/client):**

1. Install yarn _(if not installed)_: `npm install -g yarn`
2. Install dependencies: `yarn`
3. Start the dev server: `yarn dev`
4. Open the app in the browser at the URL Next.js prints (usually [http://localhost:3000](http://localhost:3000))

<br>

**Other scripts:**

- `yarn build` — Production build
- `yarn start` — Run the built app
- `yarn lint` — ESLint,
- `yarn test` — Playwright.
