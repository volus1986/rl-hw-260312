### Getting started:

**Frontend (/app/client):**

1. Install yarn _(if not installed)_: `npm install -g yarn`
2. Install dependencies: `yarn`
3. Start the dev server: `yarn dev`
4. Open the app in the browser at the URL Next.js prints (usually [http://localhost:3000](http://localhost:3000))

<br>

**Other scripts:**

- `npm run build` — Production build
- `npm run start` — Run the built app
- `npm run lint` — ESLint,
- `npm test` — Playwright.
